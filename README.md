# dev-skills

A collection of Claude Code skills for developer tooling and mobile app development.

## Skills

### [`android-emulator-optimize`](./android-emulator-optimize/SKILL.md)
Optimize Android emulator performance on any developer machine. Dynamically selects the right AVD image, device, and config settings based on host specs. Covers GPU acceleration, RAM tuning, shell setup, and common pitfalls.

## Install

```bash
npx skills add egyleader/skills
```

Install a single skill:

```bash
npx skills add egyleader/skills --skill android-emulator-optimize
```
